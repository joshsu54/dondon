# 宗門模組 06

新增八組獨立素材：宗門直牆模組、轉角柱、院門、木構樓梯、演武木樁、靈草幼苗、成長株、成熟株。每組提供可編輯 `.blend`、FBX 和 10 張 1024 × 1024 同模型角度圖，共 80 張。

開啟 `index.html` 瀏覽；`overview.jpg` 為總覽，個別 `*_10views.jpg` 為十視圖縮圖表。縮圖表每個物件採各自構圖，不表示物件之間的實際比例。

## 模組規格

- 直牆：4 m 長，根節點在底部中心，接口位於局部 X = -2 m 與 +2 m。牆上玉色飾板為實心裝飾，並非打通的格窗。
- 轉角柱：中心柱體寬 0.62 m，牆端與中心相距 0.31 m；石座較寬，拼接時容許石座與牆腳重疊。沒有自動吸附功能。
- 院門：雙扇關閉門板、拉環、鉸鏈外形、木柱與瓦頂；門框為可編輯分件，尚未建立完整門扇階層、鉸鏈動畫或互動。
- 木構樓梯：18 級、總高 3 m、踏面進深 0.28 m、寬 1.5 m，附頂端平台、支撐和扶手。這是遊戲建模尺寸，尚未實際安裝到藏經閣；也沒有完成角色通行或碰撞驗證。
- 演武木樁：沿用既有演武場的造型重新獨立建模；不修改原場地，尚無骨架、受擊或使用動畫。
- 靈草：幼苗為兩莖、成長株三莖、成熟株五莖並開花，各有獨立模型與十視圖。這三件是生長外觀，沒有生長動畫、採集後模型、採集功能或風動骨架。

## 宗門配置 v003

`Models/SectLayout/v003` 是從既有 v002 複本增加外圍牆線、四角轉角柱與東側院門的配置。南側留 4.6 m 主入口，東側為 3.4 m 院門配置區；院門門板仍為靜態關閉狀態。圍牆分段依實際邊界長度沿長度方向微調比例，尺寸與位置記錄於 `layout_info.json`。

本批樓梯、木樁及三種靈草獨立交付，尚未替換舊建築／演武場／藥圃中的物件。藏經閣上層仍缺可用樓板、樓梯安裝與通行驗證。v001 與 v002 保留，不覆寫舊版。

場景另附 3 張 1400 × 1400 預覽，不算入 80 張單項角度圖。可編輯模型均以公尺為單位，正面為 Blender -Y。基礎十視圖為前、右、後、左、四斜角、頂視、高位前視。

## 驗證範圍

`validation.json` 記錄八件模型重開、原點、有限頂點、FBX 匯回尺寸、PNG 及十個方向檢查。場景 `layout_validation.json` 核對九項既有建設的占地、場景 FBX、圍牆分段長度與預覽檔案；不是完整導航、碰撞或引擎驗證。

所有素材仍為外觀原型；尚未完成 UV／程序材質烘焙、碰撞、LOD、動畫或 Unreal 驗證。FBX 主要保留幾何與基本色。`source_integrity.json` 記錄配置來源的 SHA-256。建模及配置程式位於 `BlenderSource`，配置重建需要原專案的 SectLayout/v002，已交付的場景 .blend 可獨立開啟。
