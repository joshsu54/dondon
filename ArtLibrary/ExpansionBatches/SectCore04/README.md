# 宗門核心建設 04

六組可編輯建設：宗門山門、宗門大殿、弟子居所、演武場、靈藥圃、修煉台／聚靈陣。每組提供 `.blend`、FBX 與 10 張 1024 × 1024 同模型渲染圖，共 60 張。

另提供 `Models/SectLayout/v001/SectLayout_v001.blend` 宗門配置場景、場景 FBX 和 3 張 1400 × 1400 預覽。六項建設依獨立集合擺放，可直接調整位置。步道是配置參考，尚未驗證導航或碰撞。

開啟 `index.html` 瀏覽所有模型與角度；`overview.jpg` 為六項建設總覽。解壓縮時保留資料夾結構。

## 建設內容

- 山門：中央主門、側翼屋頂、石台階、木柱與可編輯牌匾；宗門名稱尚未指定，牌匾只有圖徽。
- 大殿：主屋頂與入口雨棚、木構柱架、灰牆格窗、前廊石階、欄杆及簡單內壇。中央入口保留通道，室內尚未完整裝潢。
- 弟子居所：兩個房間、各自門窗、屋頂及前廊。門扇為獨立物件，沒有鉸鏈、開門動畫或室內家具。
- 演武場：石板地坪、三個靜態木樁、欄杆與步法定位石。木樁仍是場地模組內分件，尚無各自十視圖或使用動畫。
- 靈藥圃：三格石框苗床，分別示範幼株、中株、成株外觀，附步道和灌溉槽。尚未做採集前後狀態、獨立生長模型交付或生長系統。
- 修煉台：八角基座、圓台、玉石陣紋、八個靈石槽、兩座陣碑與蒲團。均為靜態幾何，沒有粒子特效或修煉功能。

## 規格與限制

單位為公尺，正面為 Blender -Y，各單項根節點位於底部中心。十視圖依序為前、右、後、左、四斜角、頂視、高位前視。所有圖片來自同一模型，並非以互相獨立的概念圖假裝多視角重建。

程序材質在 FBX 中僅保留基本色，尚未做 UV 貼圖烘焙、碰撞、LOD、材質引擎重建或 Unreal 匯入驗證。模組中的子物件可編輯，不代表每個子物件都已獨立交付十視圖。`validation.json` 記錄 Blender 重開與 FBX 匯回尺寸檢查，不能替代引擎驗證。

建模腳本在 `BlenderSource/build_sect_core04.py`；重建時跳過已有完整 views.json 的素材。既有素材應建立新版本，不覆寫使用者修改的檔案。宗門場景由 `build_sect_layout.py` 組合，只讀取六件來源模型。
