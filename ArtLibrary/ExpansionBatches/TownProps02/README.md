# 青溪鎮獨立道具補充 02

本次從既有出生廣場與鐵匠鋪中，拆出 **8 件獨立道具、8 份 .blend、8 份 FBX、80 張 1024×1024 PNG**。每件道具都有自己的十視圖，沒有把整個場景的圖片當成各零件的交付。

| 道具 | 拆分範圍 |
|---|---|
| 石燈 StoneLantern | 一座完整石燈，含底座、柱、燈室、光芯與石頂 |
| 指路碑 TownWaymarker | 石碑、深色嵌板與抽象刻紋；尚無實際地名文字 |
| 長凳 TownBench | 一張木座面／石支腳長凳 |
| 鐵砧與底座 SmithAnvil | 鐵砧、砧角、尾部、木墩與鐵箍 |
| 工作台 SmithWorkbench | 桌腿、桌板、下層架；已排除桌上的工具與鐵錠 |
| 淬火桶 QuenchBarrel | 中空木桶、鐵箍與獨立水面；不是帶提把的水桶 |
| 武器架 WeaponDisplayRack | 空木架；展示劍仍待另行拆分 |
| 鐵鎚 SmithHammer | 木柄與鎚頭，調整為鎚頭朝上的展示姿態 |

所有圖片由對應模型直接渲染，無本批新增 AI 概念圖。來源模型只讀取、不修改，其 SHA-256 記錄於 source_integrity.json。零件名稱與來源存於各 model_info.json，保留網格、材質與修改器，支援後續細修。

## 十視圖及使用方式

每組包含前、右、後、左、右前、右後、左後、左前、正上方、高位正前方十個不同相機方向。正面定義為 Blender −Y；正交投影；模型尺寸單位為公尺，原點位於底部中心。長凳轉向使長邊沿 X，鐵鎚轉為直立，轉換矩陣保存在 model_info.json。

可直接開啟 Models/物件/v001/物件_v001.blend。01_Editable_Asset 是可編輯道具，90_Studio_Not_Exported 是攝影棚。已有模型時不需從圖片重新重建，圖片可作造型核對或細化參考。

## 驗證

重新開啟全部 Blender 檔、檢查非空網格與有限頂點座標、底部中心原點；FBX 匯回 Blender 後核對網格數與尺寸，要求誤差小於 1 mm。十視圖逐張檢查無裁切、可解碼、尺寸正確、相機方向不同，並檢查同組檔案非完全重複。查看 validation.json 取得檢查結果。

本批屬外觀原型，尚未製作 UV／程序材質烘焙、LOD、碰撞、抓握動畫或 Unreal 匯入驗證。石燈光芯與淬火桶水面在 FBX 的效果需於引擎內重設。

## 待補項目

展示法劍、火鉗、鐵錠、藥罐、材料袋、獨立貨架與櫃台仍需各自十視圖。上一批藥草攤、晾藥架、研缽與杵、靈草盆、丹爐、蒲團已完成原型與十視圖；靈藥圃生長階段、完整修煉台與煉丹房仍未完成。新建築下一批可優先食肆／客棧及料理道具。

## 重跑

`Blender --background --factory-startup -t 4 --python BlenderSource/extract_props.py -- --project /你的專案路徑`

可在最後加 `--only StoneLantern` 選一個物件；已有完整 views.json 的項目會跳過。驗證用 BlenderSource/verify_props.py。
