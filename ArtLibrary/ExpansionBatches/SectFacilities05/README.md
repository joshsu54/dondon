# 宗門設施與家具 05

本批新增 8 組：煉丹房、藏經閣、宗門倉庫、百子藥櫃、經卷玉簡架、閱讀書案、宗門儲物箱、弟子床鋪。每組提供可編輯 Blender、FBX 和 10 張 1024 × 1024 同模型渲染圖，共 80 張。

三棟建築各附一張 `interior_roof_hidden.png`，顯示隱藏屋頂後的配置，另外計數，不替代基本十視圖。原始 Blender 儲存時保留完整屋頂。已標記屋頂物件的 `roof_reveal` 自訂屬性，方便編輯時辨識。

`Models/SectLayout/v002` 提供宗門擴建配置的 Blender、FBX、3 張 1400 × 1400 預覽及驗證紀錄。它使用上一批六項建設，另加入三棟新建築與步道；舊 v001 保留。此配置未把床鋪放入舊居所，也未修改舊居所來源模型。

## 各項內容及限制

- 煉丹房：開放入口、後牆外煙道、藥櫃、工作書案，並重用既有 AlchemyFurnace 丹爐。沒有煙霧、火焰或煉丹功能。
- 藏經閣：雙層屋面及上層外殼，一樓有經卷架與書案；尚未建樓梯或可使用的上層樓板。
- 宗門倉庫：寬入口、靜態開啟門扇、石扶壁與六個儲物箱。
- 百子藥櫃：20 個可分別編輯的抽屜組件；尚未做櫃內滑軌、完整抽屜空腔或動畫。
- 經卷玉簡架：木架、綁束經卷與玉簡；卷軸和玉簡是架內分件，未各自交付獨立十視圖。
- 閱讀書案：木桌、竹簡、硯台、毛筆；各為靜態可編輯分件。
- 宗門儲物箱：具有內部空腔、獨立箱蓋和鉸鏈外形；未設定鉸鏈骨架、開箱動畫或互動。
- 弟子床鋪：木架、編織床墊、枕頭和折被；未做布料模擬。

單位為公尺，正面 Blender -Y，獨立素材根節點位於底部中心。十視圖為前、右、後、左、四個斜角、頂視、高位前視。模型為程序建模所得，圖片由同一模型渲染。

目前為外觀原型，尚未完成 UV／程序材質烘焙、碰撞、LOD 或 Unreal 匯入驗證。FBX 主要保留幾何與基本材質色。`validation.json` 和場景 `layout_validation.json` 記錄 Blender 內的重開與 FBX 匯回檢查，不能替代引擎驗證。

## 重建

`BlenderSource/build_facilities05.py` 建立本批 8 件素材；若已有完整 views.json 會略過。重建會用到既有專案的丹爐，可用環境變數 `XIUXIAN_PROJECT` 指定專案路徑。既有完成素材應建立新版本，避免覆蓋人工修改。

`build_sect_layout_v002.py` 組合新建築和原專案六項宗門建設；需保留原專案來源。交付 `.blend` 本身已內含幾何，不需外部模型才能開啟。先前來源的 SHA-256 記於 `source_integrity.json`。
