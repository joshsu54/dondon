# 山水環境 09

本批補上獨立水景素材：山崖瀑布 WaterfallCliff、彎曲山溪 MountainStreamBend、靈泉水潭 SpiritSpringPool。
每組都有可編輯 Blender 原檔、靜態 FBX、十張 1024 × 1024 PNG、十視圖總覽、尺寸資訊與驗證紀錄。

## 內容與使用

- 山崖瀑布：岩柱山崖、上方水源、落水簾、底潭、岸石、泡沫與水紋。
- 彎曲山溪：10 m 長 S 形溪段，水面寬 2.64 m；含溪床、岸石與蘆草。model_info.json 記錄水面兩端接口；鄰接模組仍需調整切線及岸石接縫。
- 靈泉水潭：石岸水潭、泉源岩石、玉晶、蓮葉與水紋。
- 1 Blender 單位 = 1 m；正面為 -Y，資產根物件位於底部中心。01_Editable_Asset 是可編輯分件，90_Studio_Not_Exported 為拍攝相機與燈光。
- 十視圖依序為正前、右、後、左、四個斜角、頂視、高前視，全部來自同一份固定幾何。圖像不是多張互相矛盾的 AI 概念圖。

## 驗證與限制

validation.json 記錄重新開檔、FBX 回匯尺寸與物件數、獨立水面、十種視角、圖片解析度與裁切檢查。
水流、泡沫與水紋是靜態造型，沒有流體、濺水粒子或水流動畫；FBX 只交接幾何與基本材質色。岩石分件保留交疊，植被葉片為薄片，整組不是單一水密模型。
UV／貼圖烘焙、碰撞、LOD、Unreal 匯入及水材質仍待完成。這三組尚未放進既有宗門山景，可先在 Blender 內拖入配置。
