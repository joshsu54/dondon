## 模型與圖片

素材主要來自既有鐵匠鋪及材料鋪。火鉗與材料袋重新製作較完整幾何；其他六件保留來源的可編輯幾何與材質，獨立化並置中。原始場景檔沒有修改，來源與零件名稱存於 model_info.json，SHA-256 記錄於 source_integrity.json。本批圖片全部直接由 Blender 模型渲染，沒有新增 AI 概念圖。

每件十視圖：前、右、後、左、右前、右後、左後、左前、正上方、高位正前方。正面是 Blender −Y，正交投影，尺寸單位為公尺，原點位於底部中心。開啟 Models/物件/v001/物件_v001.blend 即可編輯；01_Editable_Asset 為模型，90_Studio_Not_Exported 為攝影棚。圖片可用於比例核對和後續細化。

## 驗證與限制

逐件重新開啟 Blender、確認有效網格與有限座標、底部中心原點；FBX 匯回後核對零件數和尺寸，誤差要求小於 1 mm。80 張 PNG 逐張檢查無裁切、可解碼、1024×1024、每組十個相機方向與非重複檔案。細節見 validation.json。

目前仍是外觀原型：UV／貼圖烘焙、碰撞、LOD、握持位置、火鉗開合動畫與 Unreal 匯入驗證尚未完成。程序材質的表面細節不等於已烘焙的遊戲貼圖。
