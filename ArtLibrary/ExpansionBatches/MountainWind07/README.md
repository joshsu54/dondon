# 山景與風霧 07

本批補上原本缺少的獨立山景地形，以及 Blender 內可播放的山風、雲霧效果。

## 交付內容

| 模型 | 說明 |
| --- | --- |
| CloudpiercerPeak／凌雲孤峰 | 主峰、側峰與山腳岩層，可分件編輯 |
| MountainRidge／連綿山脊 | 三段山峰與共用山腳，供遠中景組合 |
| LayeredCliff／層岩峭壁 | 岩層與不等高側壁，未建立自動吸附接口 |
| SectSummitPlateau／宗門山頂平台 | 頂面高 48 m；中央預留 44 × 62 m 平坦區域 |
| WindPine／迎風松 | 以迎客松 v001 為來源的獨立風動變體，保留既有 v001／v002 原資產 |
| WindGrass／風動草叢 | 42 片草葉，根部固定，隨高度增加擺幅 |

每組含可編輯 .blend、靜態 .fbx、10 張 1024 × 1024 PNG 及十視圖總覽。同一模型在第 1 幀分別渲染正前、右、後、左、四個斜角、頂視與高前視，沒有用不同生成圖片冒充同一幾何。

## 場景與動畫

- `Models/MountainSanctuary/v001`：既有宗門 v003 放在山頂，搭配本批山體、迎風松和三層體積雲霧；3 張場景預覽另計。
- `Effects/WindFog/v001`：可編輯風霧場景、48 張動畫影格、4 秒 MP4（12 fps）及 GIF。
- Blender 時間軸為 24 fps，第 1～96 幀播放；第 97 幀是循環接點。松樹與草叢為形態鍵動畫，雲霧為循環紋理座標位移，不是流體或物理風力模擬。
- 播放風動請開啟 `.blend`。本批 FBX 僅輸出靜態幾何；不包含 Blender 體積材質或風動動畫。
- 雲霧是效果，不計為新增幾何模型；48 張動態影格也不計入 60 張單項十視圖。

## 尚未完成

山腳到山門的通行山路、山體接縫整理、碰撞、UV／材質烘焙、LOD、Unreal 風場與雲霧移植均未完成。部分山體互相重疊構成輪廓，未合併為單一封閉地形。場景是外觀與動畫原型，尚非可直接遊玩的開放世界地圖。

## 檢查

`validation.json` 記錄六組模型重開、FBX 回匯、尺寸、十視圖與風動根部／循環接點檢查。場景與特效檢查另見各資料夾的 validation.json；來源舊檔與安裝結果見 installation.json。
