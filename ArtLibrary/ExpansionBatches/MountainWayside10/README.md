# 山路設施 10

新增六角休憩亭 MountainRestPavilion、拱形石橋 StoneArchBridge、獨立石欄杆 TrailStoneRailing。
每組交付 Blender、FBX、10 張 1024 × 1024 PNG、十視圖總覽、尺寸／接口資料、重開與回匯驗證紀錄。

## 模型規格

- 六角休憩亭：六根木柱、三層 0.18 m 高台階、四張座椅、相對兩側開口、曲面六角青瓦屋頂與斗拱。地板高 0.54 m；柱礎間入口淨寬 1.84 m。屋頂物件帶 part=removable_roof 標記，另附 11_interior_roof_hidden.png 內部預覽；這張預覽不計入十視圖。
- 拱形石橋：9 m 橋面、中央拱下高 1.6 m、垂直厚度 0.5 m，欄杆柱礎內側淨寬 2.98 m。入口與出口踏面均高 0.5 m，中央踏面高 2.1 m。最大坡度約 71%（約 35°），場景配置時需依角色控制器需求增加階梯或調整橋拱；尚未做可通行遊戲道路驗證。
- 獨立石欄杆：底座長 3.4 m，三個立柱與兩個欄片，玉色菱形裝飾位於正面。重複排列時需調整端柱與接縫，並非自動吸附套件。

## 使用與驗證

1 Blender 單位 = 1 m，正面為 -Y。資產根物件在底部中心；接口座標載於 model_info.json。
01_Editable_Asset 為可編輯分件；90_Studio_Not_Exported 為相機與燈光。FBX 僅匯出資產幾何與基本材質色。
十視圖是正前、右、後、左、四個斜角、頂視、高前視，均由同一份幾何渲染。
驗證包含重新開檔、FBX 回匯尺寸與物件數、圖片數與解析度、視野裁切，並檢查亭柱與座椅數、屋頂支撐、石橋封閉幾何與橋面抽樣。
UV／貼圖烘焙、碰撞、LOD、Unreal 匯入、角色通行與導航均待完成。三組尚未安裝到既有山景。
