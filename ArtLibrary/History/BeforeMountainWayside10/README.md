# 修仙美術素材庫：Unreal 開發前準備

目前以 **Blender 製作模型與參考圖、之後交給 Unreal Engine** 為方向。Unity 原型與未整合的宗門核心草稿已暫停擴充。

開啟 `index.html` 可瀏覽模型、預覽與固定角度圖。解壓縮交付包後請保留整個 `ArtLibrary` 資料夾，讓相對路徑保持有效。

目前六十三組素材各有 **10 張由同一模型渲染的固定視角圖，共 630 張**，包含原有建築組合與新增獨立道具。小鎮組合另外提供總覽、俯視與街道預覽。

這不是「全遊戲美術已完成」。完整需求與待製作項目請看 `完整建模清單.md`。

## 資料夾

- `Current/`：目前採用版本的 `.blend`、`.fbx`、預覽與檢查資料。
- `Turnarounds/`：每組 10 張正交參考圖與 `views.json`；正面定義為 Blender -Y。
- `References/Current_Xianxia/`：修仙道路與迎客松等早期概念參考。它們不是模型渲染，細節可能互相矛盾。
- `References/Legacy_AlternateStyle/`：早期木屋和鐵匠鋪等其他風格參考，保留備查；目前不採用此美術方向。
- `Calibration/`：1 公尺立方體，供日後檢查 UE 匯入比例。
- `asset_catalog.json`：機器可讀素材索引與狀態。
- `checksums.json`：檔案大小及 SHA-256，供搬移時核對。

## 模型與圖片如何使用

有模型時，以 `.blend` 的實際幾何為準；視角圖用來核對比例，不必重新從圖片建模。`Current` 是交付副本，專案原始 `Models` 與舊版本保留不動。

概念圖只提供造型方向。不同角度若矛盾，先選一張主概念、在 Blender 統一幾何，再產生一致的十視圖。

## 尚未完成的遊戲交接

目前 FBX 保留幾何和基本材質色，沒有烘焙程序材質。UV、正式貼圖、碰撞、LOD、植被風動與角色骨架／動畫需要後續製作。現有「FBX 匯回驗證」是 Blender 內的檢查，**不是 Unreal 匯入驗證**。
