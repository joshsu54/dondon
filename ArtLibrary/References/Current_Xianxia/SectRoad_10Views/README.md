## 方位與造型規則

- 低位入口定義為南／正面，高平台為北／後方；從入口往平台走是上坡。
- 往北經過六階石梯後到上平台。石燈只放在上平台左右兩側。
- 路碑固定在入口附近東側：從正面看為右手邊。部分斜角與背面圖有生成偏移，請依 01 與 09 圖校正，不要把路碑移到道路中央。
- 正後方因高平台遮擋，看不到大部分低路面是合理現象；判斷高度請同時對照左右側面。

## 參考優先順序

1. **01 主造型**：決定總體外觀、路緣、石燈與路碑樣式。
2. **09 垂直俯視**：辅助道路平面輪廓、裝飾位置及石板分布。此張採直式構圖。
3. **03、05 側面**：判斷低路面、階梯與高平台的高差。側視仍帶些俯角，並非標定工程正投影。
4. **其他角度**：理解遮擋、材質與立體形狀。

圖片是分別生成的概念參考，並非同一個 3D 模型的十次精確渲染。石板接縫、草叢、階梯間距、石牆層數、石燈尺寸及局部位置可能不同。建模時先採一套一致幾何，再依主要參考補細節；不要逐張照搬所有差異，也不能保證直接把十張圖送入重建工具就得到正確模型。

## 建議拆件

- 路面：幾種可重複使用的大石板、窄填縫石、低路緣。
- 階梯：單階石踏板，組成六階階梯，再搭配兩側收邊石。
- 平台：平面鋪石與支撐側牆分開。
- 裝飾：一款石燈複用兩次，一塊路碑；苔蘚與小草另做。

先做無細節的路面、階梯和平台，再確認角色走動順暢；裂紋與苔蘚最後補。大型場景裡可把路段銜接地形，概念圖露出的厚底座不代表整條道路都必須架高。

## 可選的初始製作尺寸（設計假設，非圖片量測）

- 道路總寬約 4 公尺、總長約 11 公尺。
- 每階先用高度 0.18 公尺、踏面深度約 0.33 公尺，共六階。
- 低路面離地 0.20 公尺時，高平台頂面約 1.28 公尺。
- 最終依人物尺度、鏡頭和通行測試再調整，所有視角以同一套尺寸為準。
