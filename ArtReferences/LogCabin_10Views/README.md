## 使用與一致性說明

- 正面以主入口、階梯和露台所在的長立面定義；正面看過去左側為塔樓翼，右側為主要山牆建築。
- 以 `01_front_right.png` 決定主要外觀，`02_front.png` 輔助正面比例，`04_rear.png` 決定補完背面。其餘圖片用於了解立體造型與遮擋關係。
- 背面原圖沒有拍到，因此三扇後窗、無後門／後露台／後階梯均為此次補完設計。
- 這些圖是分別生成的概念參考，並非同一個 3D 模型的精確轉台渲染。局部窗戶數量、屋頂交接、塔樓露出位置、支柱間距及家具可能有差異；正側視和俯視也不應視為可直接量測的工程正投影。
- 遇到矛盾時依主要造型圖統一設計，不要逐張照搬差異。先建立一致的建築方塊、屋頂與露台，再處理原木和瓦片細節。
- 圖片未提供真實尺寸。可先將入口門高自行設定為 2.1 公尺作為遊戲製作的比例起點；此數字是建模假設，不是從原圖量得。
- 白灰背景、完整建築構圖和柔和光線用於減少遮擋；最終模型仍需手動建模或另行重建，不能保證十張圖片直接輸入就能自動產生正確模型。

生成方式：內建 image_gen，沒有使用 CLI/API fallback。完整使用提示詞見 `prompts.json`。
