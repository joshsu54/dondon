# 山門迎客松：主要造型參考

使用內建 image_gen 製作，延續宗門青石古道的古老山林風格。

- `01_welcoming_pine_master.png`：一棵孤立展示的迎客古松，包含扭曲樹幹、橫伸主枝、分層松冠、外露樹根與青灰山石。
- `prompt.txt`：完整生成提示詞。

此圖為造型概念參考，尚未製作 `.blend` 或 FBX 模型，也不是可以量測的工程圖。圖中無實際尺度；建模時可先以約 7 公尺樹高作為設計起點，再依人物與道路調整，特別確認伸向道路的枝條不阻擋人物與鏡頭。

建議將樹幹與主枝、松針群、根部山石、零星苔蘚與草分開製作。先做樹幹剪影，再定主枝分叉，最後配置松針層次，保留枝葉間隙。此階段不含樹木動畫或 Unity 場景整合。
