# 小鎮水井（TownWell）：10 張建模前概念參考圖

建模前先產生。依提示詞寫成設計規格，再以程式繪製十個角度的墨線上色草圖；雲端環境沒有 AI 生圖模型，所以這些是程式繪製的概念草圖，不是模型渲染，也不是 AI 繪圖。提示詞保留在 `prompts.json`，之後可改用生圖工具重新產生。

- 設計：Round stone well with timber posts, small tiled roof, windlass drum, rope and a hanging wooden bucket; spare bucket on the ground.
- 尺寸：Approx. 2.5 x 2.1 x 3.2 m; stone ring 1.8 m across, rim 0.9 m high.
- 正面＝Blender -Y；主造型依據為 05 右前斜角。草圖省略細節零件（瓦壟、編織帶、格柵條等），細節以 Blender 模型為準。
